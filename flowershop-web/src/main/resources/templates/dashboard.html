How to Use This File in Spring Boot

This single file is designed as a Dual-Mode Hybrid Template:

  1. Drop-in Spring Boot View: Save this file directly as src/main/resources/templates/dashboard.html.
  2. Full Interactive SPA Mode: All 5 tabs (POS Checkout, Custom Bouquet Builder, Perishable Stock Audit, Customer CRM, and SQL Transaction Log) work immediately in your browser with zero page reloads.
  3. Native Server POST Support: Expanding the "Spring Boot Direct Server POST Form" at the bottom of Tab 1 or submitting the Customer Registration form triggers your Spring Boot @PostMapping("/orders/checkout") and @PostMapping("/customers/register") endpoints.
